## 实现与回归覆盖

### 同行内部对齐

卡片固定十个 `data-devlead-board-section`：title/workspace/meta/focus/next/goal/blockers/progress/tasks/footer。
Chromium subgrid 中每张卡片跨同一父网格的十条共享轨道；父网格在增强分支使用 `grid-auto-rows:auto`，避免
`1fr` 与跨轨内容形成放大。非 subgrid 保留 `grid-auto-rows:1fr`、flex 等高和 footer `margin-top:auto`。
focus 3 行、next/goal 2 行 clamp 与原生 title/disclosure 全文路径不变，空字段以 visibility/aria-hidden 占位。
渲染测试钉住十轨顺序、混合长短文本和空 goal；真实几何见下。

### priority 图标与可访问性

priority 文字 badge 从 meta 移除；标题行最右改为 high 双上、medium 单上、low 单下 chevron，flex:none，
形状可独立区分。图标有本地化 `role=img`/aria-label/title、`tabIndex=0`、hover/focus tooltip、`openOnClick`
与 portal，另有 `:focus-visible`；notes chip/count/latest 保持。测试中英文 ARIA、图标数量、无文字 badge、
tooltip click/portal 与标题行末端结构均有断言；真实 hover、Tab、click/Escape 另有截图和 DOM 证据。

### 卡片状态点与面板 header

`ProjectCard` 标题左侧 StateDot 和不再使用的 `statusDot()` 已删除；LIVE StateDot 与手动刷新 `aria-busy`
IconRefresh 旋转明确保留并有样式断言。状态继续由分组、KPI 和 status 四边色表达。面板内可见 h3「项目看板」
与「只读」Tag 删除，tab 标题不动；根容器保留本地化 aria-label。LIVE、updated/rN、最右 refresh 合并为
单行 header strip，窄栏按需求允许优雅换行。KPI、blocked、notes、轮询/watch 与 Remote 行为不变。

独立 UI/UX 复核初次指出 tooltip 键盘/触屏可达性和窄栏证据不足；随后补 focus/click/portal 和真实 299.5px
几何。最终独立复核 verdict = **PASS（无 blocking concerns）**，确认 priority 键盘/点击可达、窄栏优雅换行、
十轨对齐与任务展开布局均通过。详细边界见 [ui-verification](v0.4.2-rc.10-ui-verification.log)。
