## 实现与测试面

- Host：`devlead_board_note_write` 收窄为 create/update-metadata/delete，移除 update/append/expected_bytes；
  read/list/create/write 结果派生 absolutePath，strict index 不保存该字段。read/list 与写入共用 promise 链和
  index writer lock，在稳定正文快照上惰性修复 bytes/mtime updatedAt；坏 UTF-8、超限、缺文件结构化报错且
  不提交部分修复，对账与修复失败均不重写原生正文。保留 64 KiB 单 note 模型读取与 index CAS。
- Tool：参数/output/description、undeclared-key guard、权限与错误映射同步；`DEVLEAD_POLICY_BASE` 实测
  **11,899/11,900 chars**，`DEVLEAD_BOARD_POLICY` 实测 **799/800 chars**，保留 rc.6 主动 board 引导，
  明确原生 read/write/edit、absolutePath、合法 UTF-8、≤256 KiB 与禁止手改 notes/index.json。
- Client：正文 watch key 不再含 stale index bytes；外部原生写文件由 watch+poll 刷新。当前 ready reader
  使用成功 stat 的 observedAt/observedBytes，list/chip 仍用 index metadata。DSH stat version 是 opaque token，
  不解析为 mtime；observedAt 是 client 观察时间而不是文件系统 mtime。
- 自动化新增/更新覆盖：create→原生写→read/list 对账、并发只修一次、CAS/no-op/delete、坏 UTF-8/超限/缺失、
  index 修复失败不覆盖正文、工具参数/错误/权限/输出路径、client 外部变更/live stat/错误降级/chip/reader。
- E2E probe 改为 create note → 直接写 absolutePath → note_read/list 对账 → Workspace Files/client 读取，
  保留原检查总数和真实 board/notes 磁盘 read-back。
