## 隔离 profile 浏览器验收

使用全新临时 DSH_HOME、专用 `devlead-ui-rc4` profile、scratch workspace 与真实 rc.5 Web UI。页面没有 token 或凭据写入本文。截图保存在本次验收工作区 `.tmp/board-rc4-*.jpg`，不入包。

- **响应式**：2551.5px container 下 active 三列；952.5px 下两列；337.5px 与 611.5px 下单列。各档均无横向溢出。
- **视觉**：blocked banner + 卡片强警示，高优先级使用蓝色 rail（与 blocked 橙色区分），KPI 为单行 pill，卡片无逐行可见 field labels。保存了 light/dark 与 notes reader 截图。
- **自动刷新**：外部把 board r42 改为 r43、给当前 note 增加 Live update 段落、再单独修改索引标题，三者均在不点击刷新时出现在 UI；Live 在 blur 时暂停、focus 时恢复。
- **安全与错误局部化**：Markdown 原始 `<script>` 为文本且 script 节点为 0，唯一 anchor 为 HTTPS。坏索引时 6 张项目卡仍在，只显示 notes 局部提示；坏 UTF-8 note 只在该文档显示错误，恢复文件后自动重新可读。
- **键盘与焦点**：notes chip 可用 Enter 打开，返回按钮自动获得焦点，关闭后焦点恢复原 chip；原生 summary 可展开任务。chip 有可见「笔记」文案与 28px 最小高度。
- **信息不减少**：写入超长 focus/next/goal/blocker/task 后，关闭态按设计 clamp；键盘展开原生任务 disclosure 后这些字段全部变为 `line-clamp:none`，完整长文可读，不再只能依赖 hover。
