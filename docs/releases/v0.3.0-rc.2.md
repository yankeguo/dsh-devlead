这是 **0.3.0 的 prerelease 候选**，CI 以 npm **`next`** dist-tag stage 全部 6 个包；
stage 不等于公开，维护者 approve 后才会在 registry 可见。稳定版 `latest` 仍是 **0.2.6**，
在 promote 之前 `next` 仍指向 `0.3.0-rc.1`；本候选 **不占用 `latest`**。

安装时写精确版本：

```sh
dsh plugin --profile desktop add @yankeguo/dsh-devlead-bundle@0.3.0-rc.2
```

> 刚 stage 的版本挡下，并在 dist-tag 回退时选中 npm 占位版本 `0.0.0-stage`，其 tarball
> 解包失败（`ERR_PNPM_TARBALL_EXTRACT`）。发布后 24 小时内务必写精确版本，理由与逃生口见
> [PUBLISHING.md](../PUBLISHING.md) 的「发布后的用户安装方式」。

## 自 0.3.0-rc.1 以来的内容

本版是 **DeepSeek v4.1 独立二审 + 后续复核**的修复汇总。人类命令、既有工具名/必填参数/
输出形状、错误码词表、`engines.dsh`（仍 `>=0.2.2-rc.1 <0.3.0`）保持不变；没有计划中的
breaking change。

### 高严重度：fork 继承状态阻断

- `subagent_fork` 会逐字复制父 Session 已完成 turn 的日志，其中可能包含
  `plugin:devlead/mode` / `watch` / `reset`。三个 projection 现在记录并在 fold 中跳过
  `event.seq < inheritedEventCount` 的继承事件（stateVersion 3/2/2）；fork 子会话不再继承
  DevLead 模式、watch 集或工具面。
- 补齐两条 cold/persisted fold：`scanActiveSessions` 在 cache 预筛与读取前跳过
  `origin === 'subagent'`，并用 `snapshot.inheritedEventCount` 初始化 cold replay；
  `persistedLeadRecords` 同样保留 fork 前缀。普通 Session fork 不再在 boot reconcile 中
  outrank / release 真正的 parent。
- `isEnabled` / `setEnabled` / notification hub 增加 subagent 防线；subagent Session 永远
  不是 lead occupant。

### P1 可靠性 / 安全

- **准入 fail closed**：持久语料 listing 失败、或 cache 明确标为 active 的日志读取失败时，
  `setEnabled(true)` 返回 `DEVLEAD_SESSION_UNAVAILABLE`，不在无法证明单活时放行。
- **interrupt inbox**：`restoreInputs` 失败不再丢掉替换 prompt 或回滚新 watch；降级为 warning
  并继续投递替换 prompt。
- **question gating**：人类在场的判定会跳过 `time-context` / `agent-instructions` /
  `working-directory` 等注入来源，并识别 `user-question-reply` / `user-approval`；未知 source
  kind 继续 fail closed。
- **未声明参数拒绝**：15 个模型工具统一拒绝 schema 未声明的参数（如 `promt`、
  `stopRunning`），返回 `DEVLEAD_INVALID_INPUT`，避免创建空 Session、归档但不停止工作、
  或丢弃排队输入。

### P2 修复 / 打磨

- outbox 7 天保留增加 report 写入路径的节流 prune；冻结 fold 的 `/devlead off` 会丢弃该
  lead 的 outbox 行；attach-only lead 释放后清理 hub 索引；storageDomain 晚挂载与 disposal
  竞态关闭；被 tombstone 的 holder 不再参与 supervisor/report 路由。
- DevLeadBar 渲染 settled-turn 的 assistant 摘要；wire drift 的集合降级为空；占用者标题
  单行化；`excerptLine` 剥离 C0/C1 控制字符。
- **subagent UI**：composer 工具栏的 `DevLeadIconToggle` 与 `DevLeadBar` 在 subagent Session
  不渲染；top-level Session 的两种状态行为不变。
- 打包：6 个发布包补齐 LICENSE；根 `packageManager` 固定 pnpm 12.16.1；删除 pnpm 12 已忽略
  的 `.npmrc` 安装键；修正工具数/兼容性文档。
- 测试补强：cold fold ordinary-fork 准入、boot rehydration ghost absence、stateVersion stale
  cache refold、prune throttle/failure、tool 参数登记、subagent UI render。

## 发布链路

- 打 annotated tag `v0.3.0-rc.2` 并推送即触发 `.github/workflows/publish.yml`；workflow
  按版本推导 dist-tag（prerelease → `next`），以 OIDC 短时 token stage 全部 6 包（带
  provenance），**不公开任何内容**（`NOTHING IS PUBLIC YET`）。
- 维护者在本地执行 approve（npm login + 2FA），脚本创建 prerelease GitHub Release：
  ```sh
  node scripts/promote-release.mjs --version 0.3.0-rc.2
  ```
- promote 前：`latest=0.2.6`、`next=0.3.0-rc.1`；promote 后 `next=0.3.0-rc.2`，`latest`
  仍为 0.2.6。
- tag `v0.3.0-rc.2` 一旦推送不移动/不删除/不重建；`v0.3.0-rc.1` 保持原样。
