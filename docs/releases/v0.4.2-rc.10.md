# v0.4.2-rc.10 — 项目看板同行对齐与标题/header 精简（prerelease，dist-tag `next`）

`0.4.2-rc.10` 是计划中的 `0.4.2` 补丁版候选，基于已发布并安装的 `0.4.2-rc.9`。本候选只改变
client-ui、测试、文档与版本号，不改 Host 数据层、工具、board/notes schema、Remote、`dsh.client.inject`
或 DSH 兼容面；**不是稳定版**。

```sh
dsh plugin --profile desktop add @yankeguo/dsh-devlead-bundle@0.4.2-rc.10
```

## 相对 rc.9 的变化

- **同一行卡片逐块对齐**：项目卡片固定为 title、workspace、meta、focus、next、goal、blockers、progress、
  tasks、footer 十条 section。Chromium 使用 CSS subgrid 让同一视觉行的卡片共享这十条父网格轨道，因此长短
  focus/next/goal、可选 blocker 与 notes chip 不再把后续进度、任务和 footer 推到不同高度。focus 最多 3 行，
  next/goal 最多 2 行；空字段保留不可见占位，原生 title 与任务 disclosure 仍提供完整内容。非 subgrid 环境
  保留 `grid-auto-rows:1fr`、flex 卡片等高与 footer 贴底降级。
- **priority 改为标题行图标**：高/中/低优先级分别使用双上箭头、单上箭头、下单箭头，形状本身可区分，
  颜色只作补充。图标固定在标题行最右，长标题 ellipsis 不挤压图标；hover tooltip、`role=img` 和 aria-label
  使用既有本地化「高/中/低优先级」文案。正文 badges 不再重复 priority 文字，notes chip/count/latest 保留。
- **移除卡片标题左侧旋转状态点**：`ProjectCard` 不再渲染 active/ongoing 时旋转的 `StateDot`；项目状态继续
  由分组标题、KPI 与 status 驱动的四边边框/轻底色表达。LIVE 的状态点和手动刷新按钮的 `aria-busy`
  IconRefresh 旋转、disabled 状态、状态文本、轮询与 watch 行为全部保留。
- **面板 header 只保留一行**：右侧 tab 的「项目看板」标题保持不变，面板内可见 h3 与「只读」Tag 删除；
  根容器以本地化 aria-label 保留可访问名称。LIVE 位于左侧，updated 相对时间、rN 与最右刷新按钮位于右侧
  actions，KPI 紧随其后；窄栏允许优雅换行/收缩而不横向溢出。
- **既有行为不变**：紧凑 2/3/1 列、KPI、blocked banner、status 四边色、notes reader、原生任务 disclosure、
  自动刷新/watch 与 light/dark token 映射均保留。渲染和样式测试覆盖十条 section 顺序、三档图标/ARIA、
  无 priority 文字 badge、无卡片状态 spinner、单行 header 以及 LIVE/refresh 动画边界。

## 发布边界

推送 `v0.4.2-rc.10` annotated tag 后，CI 只把 6 个包 stage 到 npm dist-tag `next`。维护者只能批准
**本次 CI 为 rc.10 生成的 6 条 staged 记录（`next`）**；rc.1、rc.4、rc.8 的未批准 staged 记录不得混入。
本候选的发布准备不包含 approve、npm 正式发布或 GitHub Release。既有 tag 不移动、不删除、不重建，稳定版
`latest` 保持 `0.4.1`，直到用户明确指示稳定版。

## English

rc.10 builds on the published rc.9 candidate with a focused project-board refinement. Cards in one visual row now
share ten internal CSS subgrid tracks, keeping corresponding sections and footers aligned with mixed content lengths;
a flex/grid fallback preserves equal-height cards where subgrid is unavailable. High, medium, and low priority move
from duplicate text badges to shape-distinct glyphs pinned to the title row's right edge, with localized tooltip and
ARIA labels. The rotating card-title status dot is removed, while LIVE and manual-refresh motion and behavior remain.
The panel no longer repeats its visible tab title or read-only tag: LIVE, updated time/revision, and the rightmost
refresh action form one compact header row. Responsive columns, KPIs, blocked warnings, status borders, notes,
disclosures, Host tools, disk schemas, Remote, client injection, and DSH `0.2.2-rc.1`–`0.2.2-rc.5` compatibility are
unchanged. See the release evidence for frozen-tree gates, real E2E totals, Chromium geometry/screenshots, and the
independent UI/UX review. Approval is limited to exactly the six new rc.10 staged records on `next`; historical
unapproved rc.1/rc.4/rc.8 records must not be mixed in.
