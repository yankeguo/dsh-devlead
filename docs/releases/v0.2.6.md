# v0.2.6 — 关注术语、按需中途汇报与侧栏标识

0.2.6 是 **patch 版本**，不包含 breaking change：人类命令、13 个主工具 + 1 个
`devlead_report`、watch / 归档 / preset / 全局单活语义、`engines.dsh`（仍为
`>=0.2.2-rc.1 <0.3.0`）都不变。本版统一中文 watch 术语，允许 lead 按需邀请被关注 Session
中途汇报，并在侧栏区分 active DevLead 行与被关注行。

## 术语统一：监督 → 关注

- 中文界面与文档把 watch 语义统一为 **关注**：`已关注会话`、`关注集合`、`关注关系`、
  `取消关注`；英文继续使用 `watched` / `watching`，不引入新的权限含义。
- watch 明确定义为**单向关注关系**：只路由 turn 通知与 `devlead_report`、允许 steering，不是
  file access、ownership 或上下级权限。内部标识符 `supervisorOf`、`isSupervised`、
  `DEVLEAD_NOT_SUPERVISED` 为兼容保留，错误语义不变。
- 历史发布说明 `v0.1.0` / `v0.2.4` 保留发布时的「监督」措辞；`v0.2.5` 的已发布 tag 内容
  也不移动。自本版起的新文案统一使用「关注/watched」。

## Lead 按需邀请中途汇报

- lead policy 与 `devlead_create_session` / `devlead_prompt_session` description 现在说明：
  对**长任务、多阶段或可能中途阻塞**的已关注 Session，lead 可以在简报中**按需**邀请子
  Session 用 `devlead_report` 提前发送关键进展、真实阻塞或需要 lead 决策的信息。
- 这不是每条简报的强制要求；`watch:false` 时 `devlead_report` 不存在，因此不要写这条建议。
- 报告仍是单向的，不是提问/等待回复通道，也不能替代最终 turn 结束通知；每轮最多 4 条不同
  报告，限流、幂等与错误码不变。

## 侧栏标识

- **Active DevLead 行**：显示与 composer DevLead 按钮激活态一致的 business 强调色圆角
  ring + 轻微 halo；**不再显示行尾盾牌/图标**，避免重复。行高、标题宽度、padding 均不位移。
- **被关注 Session 行**：行尾显示弱化的准星/目标图标（DSH primitives 中选用
  `IconGoalOutlineRegular`，13px），一眼可辨识，但不与 active ring 竞争；未 watched 行不显示。
- 新增 summary 级 `devLeadWatch` projection（`{ sessions: string[] }`），watch 集合从 lead 的
  durable 记录 fold 到每个 Session summary；行谓词因此能覆盖 cold 行、重启后的 cache 行，无需
  给被关注 Session 写日志，也不读被排除的 `devLead` digest。
- active 行只画 overlay ring，不修改 shell 行的 border/padding：`::after` 用
  `inset: 0 calc(-1 * var(--dsh-sidebar-paint-inset))` 对齐 border box，四边 1px 同宽，
  `border-radius: inherit`；halo 为 2px business tertiary。
- 可访问性：active 行保留视觉隐藏的 `aria-label`（「当前激活的 DevLead 会话」），watched 行
  aria 为「被当前 DevLead 关注」；hover card 分别显示 active/watched 文案，active 行使用小圆点
  而非盾牌。边框/颜色不是唯一信息源。

## 边界与限制

- active ring 依赖 shell 行稳定的 `data-row-key` 属性、现代浏览器 `:has` 与
  `--dsh-sidebar-paint-inset`；DSH 若改行结构/内缩值，overlay 需同步。不支持 `:has` 时
  ring 不出现，但 aria/hover 文案、watched mark 仍在。
- `::after` 与 shell 的拖放 marker 共用伪元素；active 行通常不是 drop target，拖拽 active
  行时可能重叠，未改拖拽行为。
- 搜索态使用另一套搜索结果行，不挂载 `sidebar.session.row.trailing`，因此搜索期间不显示
  active/watched 行标识；清空搜索回到普通列表后恢复。
- DSH 0.2.2-rc.1 对 blank（尚无 turn）行不渲染 trailing seat，首次 turn 后才显示标识。
- 升级前已有 watch 集合的 lead 需要 `devLeadWatch` 的 projection cache 回填（打开该 Session
  一次，或再次变更 watch/mode）；Host 启动不强制回填。
- summary 没有 archive 位；理论上 archived 但 `devLeadMode.enabled` 仍为 true 的 lead 可能影响
  行谓词，正常 active lead 不会处于 archived 状态。

## DSH 兼容性

- 继续声明 `engines.dsh >=0.2.2-rc.1 <0.3.0`，未新增 DSH API 依赖。
- 发布时在 rc.4 上重跑 installed / patch 两套完整 E2E；rc.1–rc.3 的兼容面沿用 0.2.5 的矩阵，
  发布时未单独重跑（改动集中在提示词、术语、client UI 与 summary projection）；rc.5 为发布后
