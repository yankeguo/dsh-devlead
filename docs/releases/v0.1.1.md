# v0.1.1 — 审计与加固版本

一次以官方 **DeepSeek Harness 0.2.2-rc.1** 源码为唯一强信源的全面审计、优化与打磨。
详见 [审计记录](../AUDIT.md)。

## 高严重度修复

- **修复开发 overlay 的跨运行时副本问题**：`pnpm dev:patch` 现在会校验目标 profile，
  并把本仓库注册为该 profile 的 **linked root**。此前用 `dsh --patch <绝对路径>` 启动时，
  插件会从本仓库的 pnpm `node_modules` 解析 `@deepseek-ai/*`，进程里出现第二份 DSH 运行时，
  第一次写 Session 插件记录就抛
  `gateway/internal: Receiver must be an instance of class Session`（`/devlead on` 直接失败）。
  修复后开发/E2E 与 `install-profile` 两种加载流都在真实 DSH 上通过端到端验证。

## 核心（`@yankeguo/dsh-devlead`）

- 列表/身份解析：`listSessions` 改为 options-only `signal`；身份解析穷尽（精确 id 快路径），
  不再受 `maxListedSessions` 限制；watched-only 列表不再截断到小于 watch 集合。
- 写入：补齐协作式取消；watch 容量 / 冷会话激活预检先于副作用；`flush() === false` 按
  「没有持久化参与者」处理，参与者异常只 warning。
- Workspace：去掉与 registry 重复的校验，错误码细分（缺目录 vs 不可用路径）；`title` 只作用
  于新注册记录。
- 严格解码：插件记录精确字段集、`Date` 可表示时间戳、正 turn、重复 watch id 一律拒绝 replay。
- Projection：identity 复用 + `SessionProjectionSummaryExcluded`——通知摘要不再进入每个
  Session summary/list payload。
- 通知泵：零延迟代际守卫、上限 1s 有界重试、同 id digest 去重、归档 lead 暂停、损坏 replay
  只 warning 一次。
- 性能：列表按便宜事实排序截断后再组装视图，registry 每次扫描一次（测试用计数器固定）。

## 工具与命令

- `/devlead` 解析严格对齐 `CommandInvocation.rawInput` 契约；状态视图单次 projection 快照；
  穷尽映射全部 `DEVLEAD_*` 错误码。
- `devlead_create_session` / `devlead_prompt_session` / `devlead_watch_session` 转发
  `exec.signal`；`exec.agent` 缺失时返回结构化 `DEVLEAD_AGENT_NOT_LIVE`。
- 工具输出 schema 与 protocol 视图类型编译期一致，并在运行时校验 canonical value。

## 客户端 UI 与协议

- 两入口准入逻辑收敛为纯 gate+reducer + 薄 hook；Host 未解析到命令（`value: undefined`）
  不再被当作成功（新增 `unresolved` 失败）。
- a11y live region、shell menu-surface 样式、码点安全的摘要、空值感知的 digest 行。
- protocol 导出面保持不变；补充 summary 排除的类型契约测试。

## 工程与 CI

- 新增 `scripts/e2e-smoke.mjs`：隔离 `DSH_HOME` + 真实 DSH Web，patch / installed 两条加载流
  各 25 项端到端检查。
- 新增 `scripts/check-packages.mjs` 包不变式检查（linked-root peer 规则、module table、
  别名、lockfile、CI pin）。
- 新增 `.github/workflows/verify.yml`（push/PR：frozen install → typecheck → test → build →
  check-packages）；发布工作流串行化、GitHub Release 幂等。
- `build.mjs` 清理过期内容、浏览器 externals 单一来源 + 越界导入构建期守卫；
  `install-profile.mjs` 全量预检；`trusted-publishers.sh` 能力探测。
- TypeScript 开启 `noUnusedLocals` / `noUnusedParameters`。

## 兼容性

- DeepSeek Harness：`>=0.2.2-rc.1 <0.3.0`（`engines.dsh` 不变）
- Node.js：`>=24.9`（仅构建与发布工具链）
- 协议导出面保持稳定；行为变更见 [AUDIT.md §7](../AUDIT.md#7-行为变更面向使用者)
