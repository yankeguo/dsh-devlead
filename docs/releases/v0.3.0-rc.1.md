# v0.3.0-rc.1 — 0.3.0 首个候选（prerelease，dist-tag `next`）

这是 **0.3.0 的 prerelease 候选**，发布到 npm 的 **`next`** dist-tag，**不是 `latest`**。
稳定版 `latest` 仍指向 0.2.6。安装需显式指定版本：

```sh
dsh plugin --profile desktop add @yankeguo/dsh-devlead-bundle@0.3.0-rc.1
```

内容与 [v0.3.0](v0.3.0.md) 草稿一致（additive，无 breaking）：人类命令、既有工具名/必填参数/
输出形状、错误码词表、`engines.dsh`（仍 `>=0.2.2-rc.1 <0.3.0`）都不变；主工具 13 → **14**
（新增 `devlead_retract_input`），加 1 个 `devlead_report` 共 15。DSH 兼容面 **rc.1–rc.5 全支持**。

## 本版能力（相对 0.2.6）

- **Workspace 三寻址**：`workspace` 参数接受 id / 注册路径 / 精确 title；歧义报
  `DEVLEAD_WORKSPACE_AMBIGUOUS` 列候选。
- **显式打断**：`devlead_prompt_session interrupt:true` 经 `workspace/session-stop` 停止运行中
  工作再投递替换 prompt；idle/cold no-op；stop 已提交后 followup 失败保留本次新增 watch。
- **watched 子会话问题路由**：`ask_user_question` 硬闸门转 `kind:question` report 给 lead；
  人类直聊 turn 豁免；question 不计入每轮 4 条预算；不新增错误码。
- **排队 inbox 输入**：`get_session` 附带 `queuedInputs`（id/boundary/source/摘要/入队时间，
  仅 live）；新工具 `devlead_retract_input`（仅撤本 lead 自投 relay，幂等）；
  `prompt_session interrupt_inbox`（默认 `clear-all` 不变 / `keep` / `clear-own`，快照-停止-恢复，
  结果 `retainedInputs`）。
- **全面审计修复**：4 个核心 P0（跨 kind 去重吞 question、无 source inbox 崩溃、dispose outbox
  单开竞态、interrupt 误回滚 watch）；工具面描述去重 + default 注解 + 只读并发 + kind 单一来源；
  report 指引收窄为长任务途中关键节点；command/protocol/client-ui 多处修复。

## 发布链路（本候选适配）

- **打 tag 推送即发 rc**：CI（`publish.yml`）按版本推导 dist-tag——稳定版 `latest`、prerelease
  `next`——以 OIDC 短时 token stage 全部 6 包（带 provenance），不发布任何内容。
- 人工 approve（`promote-release.mjs`，npm login + 2FA）后公开；脚本三道防误发闸门：stage 拒绝
  prerelease×latest、promote 预检拒绝以 latest stage 的 prerelease、approve 后核对
  `dist-tags.latest` 不指向本候选。
- GitHub Release 标记为 **prerelease**（`--prerelease --latest=false --verify-tag`）。
